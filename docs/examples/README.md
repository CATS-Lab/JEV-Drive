# Archived state examples / 历史状态示例

These saved states and their rendered images predate road-corridor navigation. Their `navigation.route_segments` field records the old GT-derived route input; new inputs use `navigation.corridors`. See [current navigation](../navigation.md). They remain unchanged to preserve the provenance of the existing figures.

这些保存的状态及对应图像早于道路走廊导航。`navigation.route_segments` 是旧版基于 GT 的路线输入；新输入使用 `navigation.corridors`。参见[当前导航说明](../navigation.zh-CN.md)。历史示例保持原样，以保留图像的数据来源。
