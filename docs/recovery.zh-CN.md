# 仿真回退重试与覆盖率

[English](recovery.md)

```bash
scripts/jev-drive --config configs/default.json retry-scene \
  --artifact "$JEV_ARTIFACT" --steps 99 \
  --rewind-steps 5 --max-retries 3 --output outputs/recovery-scene
```

`--steps` 不能超过场景可用的闭环时长。本地 20 秒场景扣除 0.2 秒预热后有 99 个决策区间。每次使用新的输出目录，接口后端沿用配置，不依赖 Vercel。

采样检查检测到碰撞或支持的违规后立即中止本次尝试。下一次从原始初始状态重新启动原生仿真，重放此前缓存的回答，直到失败决策之前 5 步，再向 JEV 请求新的回答。0.2 秒一步，对应回退 1 秒；重放不调用 API。每次重放和到达恢复点时都会核对模型输入：整数与标识必须一致；浮点量允许其原单位下 0.001 的误差，地图字段允许一毫米的舍入误差。超出容差会以基础设施失败结束该场景。

回退后新决策会收到明确的 `retry_context`，描述此前仿真分支的失败。这是一次尝试后的反馈，因此重试结果与首次结果分开统计。两个分支都不提供 GT 的中间轨迹点。

同一区域在**首次尝试之外最多重试 3 次**。相距不超过 5 个决策步，或距该区域首次失败位置不超过 5 米的失败，共用预算；改变违规类型不会重置次数。每个场景另设 `steps × (max_retries + 1)` 次新决策请求上限。HTTP 限流重试遵循原有客户端规则，与场景重试分别计数。认证或余额错误会停止整批实验。接口失败不触发其它驾驶策略来替代 JEV。

## 哪些问题触发回退

请求控制器每 50 ms 报告一次车辆状态。碰撞检查使用自车完整有向框和高度范围，对比同一时刻全场景目标；目标经过输入管线使用的保守重叠过滤，但不限制为最近 16 个。平面重叠超过 0.02 m²，且垂直重叠超过 0.2 m 时判为碰撞。仿真的原始交通轨迹不变。

另外检查：车身与源数据的**道路外缘**重叠长度超过 0.1 米；移动速度超过 1 m/s，且与所有包含自车中心的车道局部中心线方向均相差超过 120°；自车框中心仅位于明确标为路肩的车道。与车身底部高差超过 1.5 米的道路几何不参与对应检查。这些阈值是评估假设，并非交通违规的权威真值。普通车道边界和 ROI 裁剪边界不会触发道路外缘检查。

未知灯色、未核实单位的限速、停止标志遵守情况和实线跨越仍是**未评估**。未观察到与源道路外缘接触的道路外行驶也不判定。地图可能不完整；采样之间的接触也可能漏检。因此“未检测到违规”不保证合法驾驶或绝对无碰撞。初始导航不可用或初始状态已触发几何问题时，在 API 调用前排除并单独记录。

## 如何读结果

`experiment.json` 保留每次尝试、失败、重试区域以及：

- **首次尝试安全时间覆盖率**：首次检测到违规前完整通过检查的决策区间数，占请求区间总数的比例。
- **最佳单分支安全时间覆盖率**：各次尝试中最长的连续通过检查前缀。不会把多个分支的长度相加。
- **首次完整通过 / 重试后完整通过**：分开记录，重试不能抹去首次失败。
- **道路走廊访问比例**：通过检查的采样中，自车中心访问过的初始导航走廊数，占初始规划走廊数的比例。不是路线距离覆盖率，也不表示到达目的地。
- **距离、静止比例、无法匹配车道的采样数、新决策请求数和缓存重放数**：每次尝试分别保留，用于区分原地停住和实际推进。

每次尝试保留决策、回答来源、采样检查、控制器轨迹和原生日志。使用 `scripts/render-scene-previews.py --run <attempt-directory> --artifact "$JEV_ARTIFACT"` 生成全景和车道 GIF。全景为 GT 在上、JEV 在下；可用时纳入检测到失败的末端姿态。不要将失败分支拼接成一条成功轨迹。

多个固定场景可以在已配置的 Python/AlpaSim 环境中运行 `python -m jev_drive.evaluation.suite --manifest scenes.json --config configs/default.json --output outputs/recovery-suite --render-script scripts/render-scene-previews.py`。清单格式为 `{"scenes":[{"tag":"example","artifact":"/absolute/path/scene.usdz"}]}`。每个场景结束后更新双语索引和汇总指标，尚未完成的场景明确列出，不算作通过。
