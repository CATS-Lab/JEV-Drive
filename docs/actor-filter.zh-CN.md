# 重叠目标过滤

[English](actor-filter.md) | 简体中文

`state/actor_filter.py` 在目标 ROI 和最近 K 个目标筛选之前，过滤疑似重复车辆观测。`actor_overlap_filter: true` 默认启用；设为 `false` 可获得未过滤基线。过滤仅使用当前框及过去采样估计的速度，不读取未来轨迹。

以下是几何启发式规则，不代表已确认目标身份：

- 候选车辆框的朝向差不超过 15°，垂直交叠至少占较小高度范围的 50%。行人、骑行者、对向车辆和不同高度道路上的目标不会被合并。
- 大框至少覆盖两个小框各自面积的 80%，且自身面积至少是每个小框的 1.5 倍；两个小框基本分离，联合覆盖大框至少 55% 时，移除大框，保留两个小框。即使速度估计不一致，该规则仍使用上述几何证据。
- 其他情况下，仅对面积比不超过 1.5 的相似尺寸框去重：交叠至少覆盖小框的 80%，且速度差不超过 3 m/s。若 IoU 至少为 0.85、几乎同位置，也允许在速度缺失或不一致时去重，并保留相关证据。
- 优先保留面积更大的框，同面积时按稳定 ID 决定。只与最终保留的代表框比较，不沿交叠链传递删除。轻微或证据不一致的交叠保留在复查列表中。

每次决策的 `provenance.actor_filter` 记录过滤版本、移除 ID、代表目标及交叠证据。原始记录不会被修改。模型接收过滤后的目标列表，过滤理由不加入模型状态。该功能不改写仿真器的回放目标或已经发生的驾驶决策。当前主页的历史 rollout 示例录制于启用该过滤之前。

## 离线检查

```bash
PYTHONPATH=src python scripts/audit-actor-filter.py --run /absolute/path/to/run --render
```

使用 AlpaSim Python 环境及[安装说明](setup.zh-CN.md#带标注的结果预览)中的 Noto Sans CJK 字体。命令不调用模型/API，按既有决策时间戳采样原场景目标，输出到 `actor-cleanup/`：

- `filtered-actors.jsonl`：原始及过滤后的世界坐标目标，以及逐帧审计证据。
- `summary.json`：受影响帧数、移除观测次数、唯一目标 ID 和保留待复查的交叠。
- `before-after-en.gif`、`before-after-zh.gif`：沿记录 GT 视角的清理前后对比，不是新的 rollout。

统计覆盖源场景中所有可用目标。`removed_ids_in_original_JEV_input` 表示移除项与旧输入的交集，画面计数则只统计可见目标。这些统计不代表驾驶能力改善，效果需另行重跑验证。同一 track ID 可能在某帧保留，在证据不同的另一帧被过滤。
