# JEV 的回答如何变成驾驶控制

[English](jev-control.md) | 简体中文

提示词 **`jev-drive-v1.6`** 要求 JEV 选择速度动作和**绝对参考转角**。驾驶动作由模型选择，代码负责约束指令并生成供 AlpaSim MPC 跟踪的参考轨迹。

```mermaid
flowchart LR
    A[结构化状态 + 两个问题] --> B[JEV 动作概率]
    B --> C[选择明确动作]
    C --> D[速度更新 + 绝对转角目标]
    D --> E[变化率限制 + 渐变速度参考轨迹]
    E --> F[AlpaSim MPC 与车辆动力学]
```

## 问题和安全要求

共同提示要求整个车身留在道路外缘内、不碰撞、沿车道允许方向行驶、不驶入路肩、遵守已知交通控制事实。道路级导航不提供 GT 中间轨迹，也不能凌驾于安全要求。未知灯色仍是未知。这些是模型指令，不是防碰撞保证。

每个档位都有独立的情境和动作描述：急弯或较大路径偏差需要更明显的转向；缓弯或小偏差需要轻微修正，并明确左右方向。直行表示**零参考转角**，按转向速率限制回正，不是保持已有转弯。完整英文标准见 [questions.py](../src/jev_drive/policy/questions.py)。

v1.6 在每条 Score 描述及 Choice 选项中明确给出速度增量（m/s）或绝对转角（rad）。描述与实际执行共用 `control/action_mapping.py`。模型还能看到 `vehicle_constraints.control_mapping`，包含当前动作数值表、变化率及绝对值限幅公式、初始超速时的渐进恢复规则，以及速度渐变与恒曲率参考轨迹公式。数值由当前配置生成。提示词版本随之更新：v1.5 回答没有看到这份控制说明，不能作为 v1.6 重放缓存。

## Score 模式

每个控制轴有九个有序档位。程序验证返回分数和概率后，执行**概率唯一最高的档位**。连续分数仅保留用于诊断，不再累加到控制量。最高概率并列时明确终止该决策，不把相反动作平均成虚构的折中动作。

| 档位 | 速度动作 | 转向目标 | 默认参考转角 |
|---:|---|---|---:|
| 0 | 面临迫近危险时，以允许的最大强度制动 | 大幅右转 | −0.400 rad |
| 1 | 危险快速接近时明显制动 | 明显右转 | −0.150 rad |
| 2 | 安全间距减小时适度减速 | 适度右转 | −0.060 rad |
| 3 | 速度稍快时轻微减速 | 轻微右转 | −0.015 rad |
| 4 | 保持适合当前环境的目标速度 | 直行，回正已有转角 | 0 rad |
| 5 | 前方安全空间充足时轻微加速 | 轻微左转 | +0.015 rad |
| 6 | 车道畅通时适度加速 | 适度左转 | +0.060 rad |
| 7 | 明显低于合适速度时明显加速 | 明显左转 | +0.150 rad |
| 8 | 低速且前方足够安全时，以允许的最大强度加速 | 大幅左转 | +0.400 rad |

速度和转向是两个独立问题，不要求选同一行。数值幅度在程序中转换；发给模型的档位描述具体情境和动作。

```text
速度增量 = (选中的速度档位 − 4) × speed_score_gain
目标转角 = 转角目标表[选中的转向档位]
转角变化 = 目标转角 − 上一次转角指令
```

默认增益分别为 0.25 m/s 和 0.015 rad。轻微、适度、明显转向分别使用转向增益的 1、4、10 倍，并受最大转角限制；大幅转向使用完整的配置转角上限，兼顾微调精度和转弯范围。连续选择轻微左转，每次都请求 +0.015 rad，不会越累积越大。返回分数为 3.99、但转向最高概率档位为 4 时，目标转角就是零。在默认 0.2 秒步长和 0.8 rad/s 变化率下，已有 −0.20 rad 转角会先变为 −0.04 rad，再归零。

## Choice 模式

执行返回并验证过的 `choice` 标签，不再使用概率差。`accelerate`、`hold`、`decelerate` 分别请求 `+choice_speed_gain`、零、`−choice_speed_gain` 的速度变化。`left`、`straight`、`right` 分别请求 `+choice_steering_gain`、零、`−choice_steering_gain` 的绝对转角。

默认增益为 1 m/s 和 0.06 rad，仍需经过相同的变化率限制。两种模式的直行都明确要求参考转角回零。

## 初始化与约束

初始目标速度等于实际测得的前进速度，**即使高于配置上限，也不直接截断**。初始转角根据实测横摆角速度和同一实际速度估计。当前不支持负的初始纵向速度，会明确拒绝。

正常更新遵守加减速和速度上下界。如果初始目标超过上限，就按减速度限制逐步回落；恢复期间允许指令暂时高于上限，从而避免瞬间跳速。

例如实际初速 31.23 m/s、上限 15 m/s、减速限制 3 m/s²：第一个 0.2 秒更新后的目标为 **30.63 m/s**，不是 15 m/s。转角也同时受到幅度和变化率限制。

## 参考轨迹与执行

四秒参考轨迹从**实际速度**开始，以受限加减速度逐渐达到更新后的目标速度。行驶距离由速度曲线积分得到，再通过曲率 `tan(转角) / 轴距` 的自行车模型计算位置与朝向。每 0.2 秒重新生成参考。

指令和参考轨迹的限幅不等于车辆实测加速度的数学保证：MPC 跟踪和车辆动力学可能有偏差。除解析限幅检查外，回归测试也覆盖了原生控制器下的高速起步场景。

## 审计与兼容性

`decisions.jsonl` 保留原始回答、`score_diagnostics.selected_level`、原始指令、`increments.requested_steering_target_rad`、执行指令，以及参考轨迹的速度曲线。`outcome` 记录实际仿真运动。完全相同的重复请求使用缓存，不会重复执行动作。

本次改变了 v1.4 的控制含义，旧回答不能作为 v1.5 决策直接重放；回退实验在使用缓存种子时会校验提示词版本。旧实验与 GIF 保留为历史记录，不代表修正后控制器的表现。
